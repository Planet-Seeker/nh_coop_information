도움말

금액·기준월

금액은 조·억 단위로 반올림해 표시하며, 6월 기준 자료의 손익은 상반기 누적입니다.

자료 산출

데이터는 금융위원회 자료를 기반으로 금융감독원 자료를 보충하는 식으로 산출됩니다. 두 자료가 다르면 금융위원회 자료를 우선하며, 금융위원회 값 옆에 금융감독원 값을 별도 표기합니다. 금융감독원에만 수치가 있는 값도 별도 표기합니다.

소속·지역 구분

조합 소속 구분은 농협중앙회 홈페이지의 조직도 구분을 따릅니다. 단, 각종 순위 산정이나 지역 단위 구분은 금융위원회와 금융감독원으로 제출된 지역분류 기준을 따릅니다.

순위

특별시·광역시 조합은 전국과 광역으로(예: 송파농협 → 전국, 서울시), 그 밖의 조합은 전국·광역·기초로(예: 천안농협 → 전국, 충남, 천안시) 순위를 매깁니다. 고정이하여신비율은 낮을수록 높은 순위입니다.

표시

  • (추정): 공시 원자료가 아닌 추정값입니다.
  • (금감원): 금융감독원 자료입니다. 금융감독원 홈페이지에 명시된 대로 “국가승인통계”가 아닙니다.
  • 주황색 “금감원 ○○”: 금융위원회와 금융감독원 두 자료가 다를 때의 금융감독원 값입니다.

검색

조합명, 지역(시도·시군), 환코드(조합명 옆 6자리 숫자)로 찾을 수 있습니다.
자료
  • 금융위원회_금융통계농업협동조합정보 (공공데이터포털, 이용허락범위 제한 없음)
  • 금융감독원 금융통계정보시스템 (Open API, 비영리 이용, 국가승인통계 아님)
